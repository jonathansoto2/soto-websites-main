# Soto Websites

Production website for Soto Websites, a local business website design and digital services company.

- Astro
- TypeScript
- Tailwind CSS
- Netlify
- Netlify Functions
- Firebase Firestore
- Resend email notifications

## Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
